# Security Policy
## Reporting a Vulnerability
Please **only report minor security vulnerabilities through public GitHub issues using the security vulnerability report template**. For all other security vulnerabilities, please contact: `goalfinder@htl-leonding.ac.at`.

When submitting a report, please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)
- Affected version
