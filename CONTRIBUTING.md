# Contributing
Thank you for your interest in contributing to this project! Contributions of all kinds are welcome, including bug reports, feature requests, documentation improvements, code contributions, and community support.

## Getting Started
1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Open a Pull Request (PR).

## Coding Standards
Please follow these guidelines:
- Write clean, readable, and maintainable code.
- Follow the project's existing code style.
- Add comments where necessary.
- Include tests for new features when applicable.
- Update documentation for any user-facing changes.
More info on specific coding styles can be found withing `AGENTS.md` and within `skills/`

## Commit Messages
Use clear and descriptive commit messages.

Examples:
```
add: user profile page
fix: resolve login validation issue
update: installation instructions
refactor: simplify authentication logic
```

## Pull Request Guidelines
Before submitting a Pull Request:
- Rebase or merge the latest changes from the main branch.
- Update documentation if needed.
- Keep pull requests focused on a single change.
- Link any related issues.

## Questions
If you have questions, please create an issue.

Thank you for helping improve this project!
