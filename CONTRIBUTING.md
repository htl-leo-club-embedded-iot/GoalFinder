# Contributing
Thank you for helping improve this project. We welcome bug reports, feature requests, documentation improvements, and security reports.

Before opening an issue, please:
- Search existing issues to avoid creating duplicates.
- Ensure that you are using the latest version of the project.
- Provide as much relevant detail as possible.

## Reporting Bugs
When reporting a bug, please include the following information:

### Summary
Provide a clear and concise description of the issue.

### Environment
- Project version:
- Operating system (if applicable):
- Browser (if applicable):

### Steps to Reproduce

### Expected Behavior
Describe the behavior you expected.

### Actual Behavior
Describe the behavior that occurred.

### Logs and Screenshots
Attach any relevant logs, screenshots, stack traces, or other diagnostic information.

### Additional Context
Provide any additional context that may help identify or reproduce the issue.

## Suggesting Features
Before submitting a feature request, please provide the following information:

### Problem Statement
Describe the problem or limitation you are experiencing.

### Proposed Solution
Explain the feature or improvement you would like to see implemented.

### Alternatives Considered
Describe any alternative solutions or workarounds that have been considered.
